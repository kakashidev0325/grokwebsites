# Elysion Cat ($ECAT)

Static one-page meme-coin site generated by Meme Site Studio (template: c31-getkitty).

- No build step: Vercel serves index.html directly (vercel.json).
- One click: **🚀 Deploy** in Meme Site Studio commits this folder to GitHub and deploys it on Vercel (project `ecat`, Root Directory `ecat`).
- By hand: push this folder to GitHub, import the repo in Vercel (Root Directory = this folder if the repo holds several sites), then add the domain **elysioncat.lol** under Project → Settings → Domains.
- site.json holds every input; import it (or this whole zip) back into Meme Site Studio to update the site.

## Custom domain: elysioncat.lol

Status: Not connected

1. Push this folder to GitHub and create a Vercel project from it.
2. In Vercel → Settings → Domains, add `elysioncat.lol` (and `www.elysioncat.lol`).
3. At your registrar, in the DNS settings of `elysioncat.lol`, add:

| Type | Name | Value |
|------|------|-------|
| A | @ | 76.76.21.21 |
| CNAME | www | cname.vercel-dns.com |

   If Vercel shows a different (project-specific) IP or CNAME target in Settings → Domains, use Vercel’s values. Remove other A/AAAA records on the same name.
4. Wait for DNS to update (minutes, up to 48 h). Vercel issues HTTPS automatically.

Check: `dig +short A elysioncat.lol` should return 76.76.21.21.
