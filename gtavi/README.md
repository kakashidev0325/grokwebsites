# Grand Theft Auto VI ($GTAVI)

Static one-page meme-coin site generated by Meme Site Studio (template: c14-thegme).

- No build step: Vercel serves index.html directly (vercel.json).
- One click: **🚀 Deploy** in Meme Site Studio commits this folder to GitHub and deploys it on Vercel (project `gtavi`, Root Directory `gtavi`).
- By hand: push this folder to GitHub, import the repo in Vercel (Root Directory = this folder if the repo holds several sites), then add the domain **gtavirobin.fun** under Project → Settings → Domains.
- site.json holds every input; import it (or this whole zip) back into Meme Site Studio to update the site.

## Custom domain: gtavirobin.fun

Status: Live

1. Push this folder to GitHub and create a Vercel project from it.
2. In Vercel → Settings → Domains, add `gtavirobin.fun` (and `www.gtavirobin.fun`).
3. At your registrar, in the DNS settings of `gtavirobin.fun`, add:

| Type | Name | Value |
|------|------|-------|
| A | @ | 76.76.21.21 |
| CNAME | www | cname.vercel-dns.com |

   If Vercel shows a different (project-specific) IP or CNAME target in Settings → Domains, use Vercel’s values. Remove other A/AAAA records on the same name.
4. Wait for DNS to update (minutes, up to 48 h). Vercel issues HTTPS automatically.

Check: `dig +short A gtavirobin.fun` should return 76.76.21.21.
