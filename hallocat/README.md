# Halloween Cat ($HALLOCAT)

Static one-page meme-coin site generated by Meme Site Studio (template: c42-legofrog).

- No build step: Vercel serves index.html directly (vercel.json).
- One click: **🚀 Deploy** in Meme Site Studio commits this folder to GitHub and deploys it on Vercel (project `hallocat`, Root Directory `hallocat`).
- By hand: push this folder to GitHub, import the repo in Vercel (Root Directory = this folder if the repo holds several sites), then add the domain under Project → Settings → Domains.
- site.json holds every input; import it (or this whole zip) back into Meme Site Studio to update the site.
