## Custom domain: gtavirobin.fun

Status: Live

1. Push this folder to GitHub and create a Vercel project from it.
2. In Vercel → Settings → Domains, add `gtavirobin.fun` (and `www.gtavirobin.fun`).
3. At your registrar, in the DNS settings of `gtavirobin.fun`, add:

| Type | Name | Value |
|------|------|-------|
| A | @ | 76.76.21.21 |
| CNAME | www | cname.vercel-dns.com |

   If Vercel shows a different (project-specific) IP or CNAME target in Settings → Domains, use Vercel’s values. Remove other A/AAAA records on the same name.
4. Wait for DNS to update (minutes, up to 48 h). Vercel issues HTTPS automatically.

Check: `dig +short A gtavirobin.fun` should return 76.76.21.21.
