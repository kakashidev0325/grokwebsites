# Make Elon Great Again ($MEGA)

Static one-page meme-coin site generated by Meme Site Studio (template: clay-bubbly).

- No build step: Vercel serves index.html directly (vercel.json).
- One click: **🚀 Deploy** in Meme Site Studio commits this folder to GitHub and deploys it on Vercel (project `mega`, Root Directory `mega`).
- By hand: push this folder to GitHub, import the repo in Vercel (Root Directory = this folder if the repo holds several sites), then add the domain **megaonsol.lol** under Project → Settings → Domains.
- site.json holds every input; import it (or this whole zip) back into Meme Site Studio to update the site.

## Custom domain: megaonsol.lol

Status: Live

1. Push this folder to GitHub and create a Vercel project from it.
2. In Vercel → Settings → Domains, add `megaonsol.lol` (and `www.megaonsol.lol`).
3. At your registrar, in the DNS settings of `megaonsol.lol`, add:

| Type | Name | Value |
|------|------|-------|
| A | @ | 216.150.1.1 |
| CNAME | www | 79ca2af6cfb20d43.vercel-dns-016.com |

   If Vercel shows a different (project-specific) IP or CNAME target in Settings → Domains, use Vercel’s values. Remove other A/AAAA records on the same name.
4. Wait for DNS to update (minutes, up to 48 h). Vercel issues HTTPS automatically.

Check: `dig +short A megaonsol.lol` should return 216.150.1.1.
