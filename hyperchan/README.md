# Hyper-Chan ($HYPERCHAN)

Static one-page meme-coin site generated by Meme Site Studio (template: ut-tanukibnb).

- No build step: Vercel serves index.html directly (vercel.json).
- One click: **🚀 Deploy** in Meme Site Studio commits this folder to GitHub and deploys it on Vercel (project `hyperchan`, Root Directory `hyperchan`).
- By hand: push this folder to GitHub, import the repo in Vercel (Root Directory = this folder if the repo holds several sites), then add the domain **hyperchan.lol** under Project → Settings → Domains.
- site.json holds every input; import it (or this whole zip) back into Meme Site Studio to update the site.

## Custom domain: hyperchan.lol

Status: Live

1. Push this folder to GitHub and create a Vercel project from it.
2. In Vercel → Settings → Domains, add `hyperchan.lol` (and `www.hyperchan.lol`).
3. At your registrar, in the DNS settings of `hyperchan.lol`, add:

| Type | Name | Value |
|------|------|-------|
| A | @ | 76.76.21.21 |
| CNAME | www | cname.vercel-dns.com |

   If Vercel shows a different (project-specific) IP or CNAME target in Settings → Domains, use Vercel’s values. Remove other A/AAAA records on the same name.
4. Wait for DNS to update (minutes, up to 48 h). Vercel issues HTTPS automatically.

Check: `dig +short A hyperchan.lol` should return 76.76.21.21.
